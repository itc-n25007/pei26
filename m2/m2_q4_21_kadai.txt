Pythonの演算子について
1.算術演算子
+: 足し算　　例 10+3　結果　13
-: 引き算　　例 10-3　結果　7
*: 掛け算　　例 10*3　結果　30
/: 割り算　　例 10/3　結果　3.33.....
//: 整数の割り算（切り捨て）　　例 10//3　例　3
%: あまりを求める　　例 10%3　結果　1
**: 累乗（べき乗）　 例 2**3　　例 8

2.比較演算子（値を比較する演算子）
==: 等しい　　例 5==5 → True
!=:  等しくない　　例 5!=3 → True
>:より大きい　　例 5 > 3 → True
<:より小さい　　例 3 < 5 → True
>=: 以上　　例 5>=5 → True
<=: 以下　　例 3<=5 → True

3.論理演算子
and: 両方の条件がTrueならTrue　　例 5 > 3 and 4 > 2 → True
or: どちらか一方でもTrueならTrue　　例 5 < 3 or 4 > 2 → True
not: 条件の結果を反対にする　　例 not 5 > 3 → False

4.演算子の優先順位
() ：括弧
** ：累乗
+x、-x、~x ：符号などの単項演算子
*、/、//、% ：掛け算・割り算など
+、- ：足し算・引き算
<、<=、>、>=、==、!= ：比較演算子
not ：論理否定
and ：論理積
or ：論理和
